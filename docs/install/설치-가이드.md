# thegolfapp 설치 가이드

이 문서는 thegolfapp을 처음 설치하는 사람을 위한 것이다. 구조는 단순하다.

```
관리자 휴대폰 앱 (Expo / React Native)
        │  HTTP  (API_BASE 주소로 접속)
        ▼
백엔드 서버 (Node.js + Express + Prisma + SQLite)
        │
        ├─ DB 파일: backend/prisma/dev.db (회원·일정·라운드 전부 여기 저장)
        └─ Gemini API: 스코어카드 OCR (서버에서만 호출, 키는 서버 .env에만)
```

계정은 관리자 하나뿐이고, 회원은 앱에 가입하지 않는다. 설치도 "서버 1대 + 관리자 폰에 앱"이 전부다.

## 0. 준비물

| 항목 | 요구사항 |
|---|---|
| 서버 | Windows PC 또는 Linux 서버 1대. 항상 켜져 있고 폰과 통신 가능해야 함 |
| Node.js | 20 LTS 이상 (개발·검증은 Node 24) |
| Git | 레포를 받을 때 필요 |
| Gemini API 키 | OCR을 쓸 때만 필요 (없으면 OCR만 503 안내, 나머지 기능은 동작) |
| Expo 계정 | 휴대폰 앱 APK를 빌드할 때 필요 (무료) |

## 1. 백엔드 설치 (서버)

```bash
git clone https://github.com/JayKim76/thegolfapp.git
cd thegolfapp/backend
npm install
```

### 1-1. 환경변수 파일 만들기

`backend/.env`를 아래 내용으로 만든다. `.env.example`을 복사해서 시작하면 된다.

```env
DATABASE_URL="file:./dev.db"
PORT=3000

ADMIN_ID=admin
ADMIN_PASSWORD=여기에-실제-비밀번호
ADMIN_TOKEN=여기에-랜덤한-긴-문자열

GEMINI_API_KEY=여기에-Gemini-키
```

- `ADMIN_PASSWORD`와 `ADMIN_TOKEN`의 기본값(1234 / dev-admin-token)은 개발용이다. **실사용 전에 반드시 바꾼다.**
- `DATABASE_URL`의 경로는 `backend/prisma/` 기준이다. 즉 DB 파일은 `backend/prisma/dev.db`가 된다.
- `.env`는 Git에 올라가지 않는다 (.gitignore 적용). 서버에만 둔다.

### 1-2. DB 만들고 초기 데이터 넣기

```bash
npx prisma migrate deploy   # 테이블 생성/갱신
npm run seed                # 모임 1개 + 테스트 회원 30명 + 스코어 116건
```

주의: **seed는 기존 데이터를 전부 지우고 다시 넣는다.** 초기 구축 때 딱 한 번만 실행하고, 운영이 시작된 뒤에는 절대 다시 실행하지 않는다.

### 1-3. 실행해서 확인

```bash
npm run dev    # 개발용 (파일 수정 시 자동 재시작)
```

브라우저나 curl로 확인한다.

```bash
curl http://localhost:3000/             # "The Golf App Backend is running!"
curl http://localhost:3000/api/club     # 모임 정보 + 회원 수
curl http://localhost:3000/api/club/stats
curl -X POST http://localhost:3000/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"id":"admin","password":"설정한 비밀번호"}'   # token이 돌아오면 로그인 경로 정상
```

운영 실행(배포) 방법은 서버-세팅.md를 본다. 요약하면 `npm run build` 후 `node dist/app.js`를 pm2/systemd로 상시 실행한다.

## 2. 휴대폰 앱 설치 (관리자 폰)

앱이 접속할 서버 주소는 코드에 들어 있다. **빌드 전에 반드시 서버 주소부터 맞춘다.**

`mobile/services/AuthService.ts`의 한 줄:

```ts
export const API_BASE = 'http://192.168.10.107:3000';  // ← 실제 서버 IP/도메인으로 교체
```

- 서버와 폰이 같은 공유기(같은 Wi-Fi)에 있으면 서버 PC의 내부 IP(예: 192.168.x.x)를 쓴다.
- 외부에서도 쓰려면 도메인 + HTTPS가 필요하다 (서버-세팅.md 4번).

### 방법 A. 개발용으로 바로 실행 (Expo Go / 개발 서버)

```bash
cd thegolfapp/mobile
npm install
npx expo start
```

폰에서 QR을 찍어 실행한다. PC와 폰이 같은 네트워크에 있어야 한다.

### 방법 B. APK를 만들어 폰에 설치 (실사용 권장)

```bash
npm install -g eas-cli
eas login
cd thegolfapp/mobile
eas build -p android --profile preview
```

- `preview` 프로필이 내부 배포용 APK를 만든다 (eas.json에 설정돼 있음). 빌드가 끝나면 다운로드 링크가 나오고, 그 APK를 폰에 설치하면 된다.
- 서버 주소(API_BASE)를 바꾼 뒤에는 **반드시 다시 빌드**해야 한다. 주소가 앱 안에 구워지기 때문이다.
- iOS는 아직 번들 ID가 app.json에 설정돼 있지 않다. iPhone에 배포하려면 Apple 개발자 계정과 bundleIdentifier 설정이 먼저 필요하다. 지금 기준 실사용은 Android다.

## 3. 웹 프로토타입 (선택, 내부 확인용)

루트 폴더의 웹 앱은 목업 데이터로 도는 프로토타입이다. 운영 대상이 아니며, 화면 확인용으로만 쓴다.

```bash
cd thegolfapp
npm install
# .env.local에 GEMINI_API_KEY=... (웹 AI 기능 확인용. 키가 브라우저에 노출되는 구조라 내부 테스트에서만)
npm run dev   # http://localhost:3000
```

백엔드도 포트 3000을 쓰므로, 같은 PC에서 같이 띄울 때는 한쪽 포트를 바꾼다 (백엔드 .env의 PORT 또는 vite.config.ts).

## 4. 설치 완료 체크리스트

- [ ] `curl localhost:3000/api/club`에서 모임과 회원 수가 나온다
- [ ] 관리자 로그인이 된다 (기본 비밀번호를 바꾼 뒤의 값으로)
- [ ] 폰 앱에서 회원 목록이 보인다 (서버 연결 확인)
- [ ] 회원 1명을 앱에서 등록해 보고, 서버를 재시작한 뒤에도 남아 있다 (DB 저장 확인)
- [ ] OCR을 쓸 거면: 스코어카드 사진으로 인식 테스트. 키가 없으면 "서버에 GEMINI_API_KEY가 설정되지 않았습니다" 안내가 뜨는 것이 정상
- [ ] DB 백업 1회 실행해 보기 (유지보수.md)
